1. What the App Does & How It's Shaped

The Fake-Real Detector evaluates internship postings, job offers, scholarship links, and messages for scam indicators and legitimate trust signals. It returns a calibrated Trust Score (1–10), an overarching Verdict (Safe, Caution, or High Risk), a summary paragraph, and an itemized two-column grid showing specific reasons paired with verbatim evidence tags.

Rather than a monolithic script, the system uses two clean engineering patterns:

  • Frontend: Controller-Presenter Pattern — Separates user input capture and validation (Controller) from HTTP transport (API Client) and UI rendering (Presenter).
  • Backend: Layered Strategy Pattern — Decouples HTTP request routing from analysis orchestration and keeps the deterministic pattern matcher (Rules) independent from the AI model (OpenRouter).

3. Code Tour: Tracing a Single Check

Follow a user submitting text through these three exact files:

Stop 1: The Input & Empty Guard — src/client/controller.ts

Function: validateAndSanitizeInput() and initController()

When the user clicks "Check Offer", the controller intercepts the submission. If the text is empty or whitespace-only, it halts silently without firing network requests or displaying errors. If valid, it disables the button and calls the API service.

Stop 2: The Orchestration & Fallback — src/analyzer/orchestrator.ts

Function: analyzeContent()

The Express route forwards the request payload to the orchestrator. If an OPENROUTER_API_KEY is present in .env, it requests contextual reasoning from OpenRouter. If no key is set or the network is unavailable, it automatically executes the local rule engine without throwing any unhandled errors.

Stop 3: Pattern Detection & Evidence Extraction — src/analyzer/rules.ts

Function: evaluateRules() and individual rules (e.g. upfrontFeeRule, eduDomainRule)

Each rule evaluates the input using deterministic regexes. When a pattern matches, it produces a Finding containing an explanation string and an array of exact verbatim quote snippets (evidences: string[]) extracted directly from the user's input.

4. To Change This, Start Here

  • Add a new scam detection rule: Go to src/analyzer/rules.ts, define a new Rule object with regex matching and score impact, and add it to the activeRules array. Add a test in src/analyzer/rules.test.ts.
  • Change the UI colors or typography: Edit src/client/style.css or utility classes in public/index.html, then run npm run build:css.
  • Switch OpenRouter AI model: Set OPENROUTER_MODEL=meta-llama/llama-3.3-70b-instruct or another model in your .env file.
  • Modify score badge thresholds: Edit getBadgeTheme() in src/client/presenter.ts.

5. A Practice to Reuse: Resilient Layered Strategy Pattern

The Takeaway: When building AI-powered features, never couple your web router or UI directly to an external LLM API.

By wrapping AI calls behind an Orchestrator that seamlessly defaults to local deterministic heuristics, the application is 100% testable offline, never breaks during live demos if rate limits or network issues strike, and allows testing the UI contracts completely independently from LLM latency.
